HideSheathedLeft 手动安装说明（不用脚本，全手动）
==================================================
适用：Dark Souls III / Steam / 1.15.0（64 位）
默认游戏目录（下文用 <游戏> 表示）：
    D:\Steam\steamapps\common\DARK SOULS III\Game

--------------------------------------------------------------------------
0. 先做备份（复制一份放别处，出问题能立刻还原）
--------------------------------------------------------------------------
    <游戏>\HideSheathedLeft.dll        （如果已存在）
    <游戏>\HideSheathedLeft.ini        （如果已存在）
    <游戏>\xinput1_3.dll               （如果已存在，见第 3 步的说明）
    <游戏>\chr\c0000.chrbnd.dcx        （玩家模型，原版约 43.8 KB）

--------------------------------------------------------------------------
1. 复制玩家模型
--------------------------------------------------------------------------
    本包 files\c0000.chrbnd.dcx
      -> <游戏>\chr\c0000.chrbnd.dcx          （覆盖，约 47.2 KB）

    它只做了一件事：在玩家模型末尾追加两个挂点 382 / 383，位置 (0, -1000, 0)，
    别的什么都没动（原版 382 条挂点一条未改）。

--------------------------------------------------------------------------
2. 复制 mod 本体与配置
--------------------------------------------------------------------------
    本包 files\HideSheathedLeft.dll
      -> <游戏>\HideSheathedLeft.dll          （约 213 KB）
    本包 files\HideSheathedLeft.ini
      -> <游戏>\HideSheathedLeft.ini

    ini 关键项（默认值就是可用配置）：
        HideLeftHang=1        核心效果：收起状态的左手道具不再挂背上
        HidePairedOffhand=1   成对武器单持时隐藏副手模型
        PairedFields=1,2,3    隐藏右侧哪些模型；想保留刀鞘就改成 1
        HidePoly=382          停放挂点 id（383 备用；-1 = 复现旧的黑三角 bug）
        IntervalSeconds=1     每秒重申一次
        ExtraMods=            必须留空
        Probe=0               0 = 正常使用；1 = 只观察不写数据（诊断用）

--------------------------------------------------------------------------
3. 复制加载器（xinput1_3.dll）
--------------------------------------------------------------------------
    本包 files\xinput1_3.dll
      -> <游戏>\xinput1_3.dll                  （约 197 KB）

    这个文件的作用只是"让游戏把我们的 DLL 加载起来"：它冒充 xinput1_3，
    再把 XInput 的第 1~8 号导出函数原样转发给系统的 xinput1_3.dll，
    因此不影响手柄功能。

    ★ 如果你游戏目录里**已经有一个别人的 xinput1_3.dll**（例如某个按键提示
      mod、DKP 加载器），覆盖它会让那个 mod 失效。两种处理方式：
        a) 想保留那个 mod：把它的文件改名备份（例如 xinput1_3.dll.old），
           然后仍按上面覆盖 —— 缺点是那个 mod 不再生效；
        b) 你已经用 ModEngine 之类的加载器：不要覆盖，改用它把
           HideSheathedLeft.dll 挂进游戏即可（ini 与模型文件照上面复制）。

--------------------------------------------------------------------------
4. 角色模型补丁（382/383 挂点，164 个 NPC 模型）
--------------------------------------------------------------------------
    玩家模型在第 1 步已经处理好；其余 164 个角色模型需要补丁器批量追加
    （手动改 165 个文件不现实）：

        cd <本包>
        powershell -ExecutionPolicy Bypass -File tools\patch-character-models.ps1 -DryRun
        powershell -ExecutionPolicy Bypass -File tools\patch-character-models.ps1

    等价的手动命令（工具直接调用）：
        tools\ds3tae.exe parkdir "<游戏>\chr" INPLACE "382,383" "0,-1000,0" 0 "chrbnd"

    说明：它给每个还没有 382/383 的 chr\*.chrbnd.dcx 追加这两个挂点，且**逐文件校验**
    （骨骼表 / 材质 / 网格 / 缓冲布局必须不变、原挂点条目必须一条没动），
    不满足就跳过不写；已经有 382/383 的文件会跳过，重复执行无副作用。
    运行前请关掉游戏。

--------------------------------------------------------------------------
5. 验证安装成功
--------------------------------------------------------------------------
    启动游戏，然后看 <游戏>\HideSheathedLeft.log，应该出现类似：

        config: HideLeftHang=1 HidePairedOffhand=1 PairedFields=111 IntervalSeconds=1 Log=1 HidePoly=382 Probe=0
        param tables located: 5
        applied 3185 field write(s) over 455 row(s) in 5 table(s)

    有 "applied ..." 就说明参数写入生效了。进游戏验证效果：
      * 左手拿盾/武器，右手武器双持 → 左手那件道具应该**看不见**（不在背上）；
      * 取消双持 / 左手攻击 → 道具恢复正常显示。

    没有日志或没有 applied：确认 ini 里 Probe=0、ExtraMods 为空，且
    HideSheathedLeft.dll / xinput1_3.dll 都在 <游戏> 根目录下。

--------------------------------------------------------------------------
6. 完全卸载（还原）
--------------------------------------------------------------------------
    只关效果（保留文件）：
        ini 里把 HideLeftHang=0、HidePairedOffhand=0（存盘，1 秒生效）

    还原到原版：
        a) 删掉 <游戏>\HideSheathedLeft.dll 与 <游戏>\HideSheathedLeft.ini；
        b) 把备份的 xinput1_3.dll 放回去（没有别的加载器时就删掉这个文件）；
        c) 删掉 <游戏>\chr\c0000.chrbnd.dcx 以及其它 loose 的 chr\*.chrbnd.dcx
           —— 游戏会自动退回读取打包（Data*.bdt）里的原始模型；
           或者用第 0 步的备份逐个放回。

--------------------------------------------------------------------------
7. 常见问题
--------------------------------------------------------------------------
* 又出现黑三角/闪烁：把 ini 里 HidePoly 改成 383（存盘 1 秒生效）；仍不行说明
  chr\c0000.chrbnd.dcx 没换成功（对比大小应为约 47.2 KB）。
* 某次启动后道具照旧挂背上（没有黑三角）：这是已知的"参数表多副本"问题，
  mod 只打到了扫到的那几份；重启游戏通常即可恢复。
* 某个角色/武器外观异常：删掉对应的 loose chr\<角色>.chrbnd.dcx，单独回退那一个。
* 换装 / 模型类 mod 覆盖了 chr\*.chrbnd.dcx 之后：重跑第 4 步的补丁器。
* 联机：本 mod 只改本地内存与模型文件，但联机有服务端存档检查风险，建议离线使用。
